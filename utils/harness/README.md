### `generate_random_tree(size: int, seed: Optional[int] = None, sparsity: float = 0.0, skew: float = 0.0, values: Optional[Iterable[int]] = None, bst: bool = False) -> Optional[TreeNode]`

A random binary tree with `size` nodes.

The tree grows one node at a time. Each new node fills one of the empty
child slots of the tree so far. Which slot is chosen is controlled by:

sparsity in [0, 1]: 0 fills the shallowest slots first, so the tree is
    as bushy as a complete tree; 1 fills the deepest slots, so the tree
    is a long chain. In between, each node picks deep with probability
    `sparsity` and shallow otherwise.
skew in [-1, 1]: -1 always takes a left slot when one is available at
    the chosen depth, 1 always takes a right one, 0 is even.
values: the node values, in the order the tree grows; default is 1..size shuffled.
    With bst=True the values are sorted and assigned in inorder, so the
    tree is a valid BST with the same shape.
seed: fixes the tree; the global random state is untouched.

### `build_graph_from_edge_list(edges, directed: bool = False)`

A dict of dicts from an edge list, every edge weighted 0. directed
adds each edge one way only, as adjacency does.

### `adjacency(edges: list, n: Optional[int] = None, reverse: bool = False, directed: bool = True, weighted: bool = False)`

Adjacency from an edge list. Each edge is [a, b] or, with weighted,
[a, b, w]. Unweighted returns a dict of lists in edge order; weighted a
dict of dicts, `adj[a][b] = w`. With n, nodes 0 to n - 1 are all keys,
isolated ones with an empty list. reverse reads each edge as b to a.
directed=False adds both directions.

### `indegrees(edges: list, n: Optional[int] = None, reverse: bool = False, directed: bool = True, type = defaultdict)`

In-degree of every node from an edge list, each edge [a, b] counting
one into b. Default is a defaultdict(int), any node reading 0; with n,
nodes 0 to n - 1 are all keys. type=list needs n and returns a plain
list. reverse reads each edge as b to a. directed=False counts the edge
into a as well, so the result is the plain degree of every node.

### `levels(q: Deque, grid = None, seen: Optional[set] = None, grouped: bool = False, eq = None, lt = None, lte = None, gt = None, gte = None) -> Iterator[tuple[int, Any]]`

Level-order BFS over a deque the caller keeps pushing onto.

Yields (d, item) for every item popped, where d is the level the item
was pushed at, starting from 0 for the items already in q. The caller
appends the next level's items to q inside the loop body. With grouped=True
yields (d, items) once per level, items being the whole level as a list.

Every popped item is checked before it is yielded. With eq, lt, lte, gt or
gte, an item whose value fails one of them is dropped; the value is
`grid[item[0]][item[1]]` when grid is given, else the item itself. With
seen, an item already in seen is dropped and a kept item is added to it,
so the caller can push without checking.

## sequences

### `lcs(a: Sequence[Any], b: Sequence[Any], full: bool = False, type = int)`

Longest common subsequence of a and b.

Row i and column j of the table stand for the prefixes a[:i] and b[:j],
so row 0 and column 0 are the empty prefix. With type=int (the default)
each cell holds the length; with type=str, list or tuple it holds one
LCS itself, built as that type. Plain lcs(a, b) is the last cell,
`dp[-1][-1]`; full returns the whole table.

## index combinations

### `pairs(n: int, type: Maker = tuple, back: bool = False) -> Iterator[Any]`

Every (i, j) with 0 <= i < j < n, in lexicographic order.

With back, the pairs are grouped by the later index instead: for each
j in turn, every (i, j) with i < j. That is the dp order, where cell j
looks back at every earlier cell.

Each pair is built by type: tuple by default, list for a LeetCode answer.

### `same_rows(a: Sequence[Iterable[Any]], b: Sequence[Iterable[Any]]) -> bool`

Row i of a and row i of b hold the same elements, in any order.

The rows themselves stay in order: an adjacency list keyed by index.

### `same_seq(a: Iterable[Any], b: Iterable[Any]) -> bool`

The same elements in the same order, whatever the container.

A tuple from divmod against a list in the assert: (1, 2) matches [1, 2].

### `uses(cls: type, *helpers: Callable[..., Any]) -> bool`

Every helper is called somewhere in the source of cls.

Raises AssertionError naming the first helper cls never calls. The
check reads the class as written, so it lives in the test block of a
solve and goes with the asserts, never to leetcode.

### `avoids(cls: type, *helpers: Callable[..., Any]) -> bool`

No helper is called anywhere in the source of cls.

The mirror of uses: for a drill whose rep is writing the helper by
hand, so a call to the library version is a fail. Raises
AssertionError naming the first helper cls calls.

### `folds(cls: type, op: str, start: bool = False, where: bool = False, block: bool = False) -> bool`

The mu source of cls has a fold of op (sum, max, min, count) with
each form asked for: start is `from e`, where is `if cond`, block is
a block in place of `: value`.

The mu source is the `# mu <version>` block quoted above the class in
its file. A Python solve has no such block and no fold to check, so
it passes. Raises AssertionError naming the fold it did not find.

### `tle(method: Callable[..., Any], num: int) -> bool`

method answers the case that timed out on leetcode, in time.

`make tle` saves the case as .prepare_cache/<num>.tle.json: the
arguments, the answer of the reference solution and the seconds the
reference takes. The call must return that answer within TLE_SLACK
times those seconds. Raises AssertionError that names the failure:
the first answer that differs, or the seconds taken against the
seconds allowed.

### `triples(n: int, type: Maker = tuple) -> Iterator[Any]`

Every (i, j, k) with 0 <= i < j < k < n, in lexicographic order.

Each triple is built by type: tuple by default, list for a LeetCode answer.

### `substrings(s: Sequence, by: str = 'start') -> Iterator`

Every slice s[i:j] with 0 <= i < j <= len(s), each position once.

by picks the order: "start" groups the slices by where they start,
shortest first; "end" groups them by where they end, longest first;
"length" gives every slice of length 1, then of length 2, and so on,
left to right. A list gives its subarrays the same way.

## digits

### `to_digits(num: int | str, reverse: bool = False, base: int = 10) -> list[int]`

The digits of num in the given base as ints, most significant first.

With reverse=True the least significant digit comes first, so digit i
is the coefficient of base**i. A negative int loses its sign. A str is
read one character at a time, so leading zeros are kept; base=2 gives
the bits.

### `to_int(digits: list[int], reverse: bool = False, base: int = 10) -> int`

The int whose digits in the given base are the list, most significant first.

With reverse=True the list is read least significant first, the inverse
of to_digits(num, reverse=True). An empty list is 0. base=2 reads bits.

### `num_digits(num: int, base: int = 10) -> int`

The count of digits of num in the given base; 0 has one digit.

A negative int loses its sign. It does not convert num to a str, so it
is fast on big ints and has no int max str digits limit.

### `class Multiset(self, iterable = None, /, **kwds)`

A Counter whose keys vanish when their count hits 0.

`m[k] += 1` and `m[k] -= 1` are the whole interface. With a plain
Counter, `m[k] -= 1` leaves the key behind at 0, so `len(m)` and
`k in m` stop meaning what a sliding window needs them to mean.
Negative counts are kept: only an exact 0 deletes.

### `count_pairs(xs: Iterable[Any], key: Optional[Callable[[Any], Any]] = None, lookup: Optional[Callable[[Any], Any]] = None) -> int`

Count the index pairs i < j with key(xs[i]) == lookup(xs[j]), in one pass.

key(x) is the key x is stored under and lookup(x) is the key x looks up.
With key left out the key is x itself; with lookup left out it is key, so
plain count_pairs(xs) counts the pairs of equal values.

>>> count_pairs([1, 2, 3, 1, 1, 3])
4
>>> count_pairs([1, 6, 3, 11, 8], key=lambda x: x % 5)
4
>>> count_pairs([3, 1, 4, 6, 3], lookup=lambda x: x - 2)
2

### `count_subarrays(xs: Iterable[Any], key: Callable[[Any], bool], pairs: bool = False) -> int`

Count the subarrays of xs in which every element passes key, or, with
pairs, every adjacent pair (a, b) passes key(a, b).

A maximal block that passes holds n * (n + 1) // 2 subarrays for its
length n; the running count adds the current block length at each step.
With pairs, a single element has no pair, so a block starts at length 1.

>>> count_subarrays([1, 3, 2, 5, 4], lambda v: v % 2 == 1)
4
>>> count_subarrays([3, 2, 1, 4], lambda a, b: b == a - 1, pairs=True)
7

### `max_diff(xs: Iterable[Any], key: Optional[Callable[[Any], Any]] = None, reverse: bool = False, from_right: bool = False) -> list[Any]`

The largest key(xs[j]) - key(xs[i]) with i < j, so far, for each j
from 1: one value per index after the first.

key(x) is the value compared; with key left out it is x itself. reverse
flips the difference to key(xs[i]) - key(xs[j]): the largest fall, not
the largest rise.

from_right scans from the right end: the value at i is the best
difference over all pairs i' < j with i' >= i, one value per index
before the last, in index order.

>>> max_diff([12, 6, 1, 2, 7])
[-6, -5, 1, 6]
>>> max_diff([12, 6, 1, 2, 7], reverse=True)
[6, 11, 11, 11]
>>> max_diff([12, 6, 1, 2, 7], from_right=True)
[6, 6, 6, 5]
>>> max_diff([12, 6, 1, 2, 7], reverse=True, from_right=True)
[11, 5, -1, -5]
>>> max([0, *max_diff([7, 6, 4, 3, 1])])
0

### `primes(lo: Optional[int] = None, hi: Optional[int] = None, count: Optional[int] = None) -> list[int]`

The primes from lo to hi, both ends included, in order; primes(n)
alone is the primes up to n, and primes(count=k) the first k primes.
primes(10) is [2, 3, 5, 7], primes(11, 29) is [11, 13, 17, 19, 23, 29]
and primes(count=4) is [2, 3, 5, 7].

A segmented sieve: the primes up to the square root of hi mark their
multiples in lo..hi alone, so a short range high up, primes(10**9,
10**9 + 100), costs the segment and not the billion below it. The
first k primes are sieved up to Rosser's bound k (ln k + ln ln k),
which the k-th prime is under from k = 6 on.
