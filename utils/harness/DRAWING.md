# Drawing functions

Generated by `make drawing-doc` from utils/readme/drawing_doc.py.

## `print(grid)`

`print` draws what it recognises: a list of lists is a table.

```python
dp = [[0, 1, 1, 1], [1, 2, 3, 4], [1, 3, 6, 10]]
print(dp)
```

```text
┏━━━┳━━━┳━━━┳━━━┳━━━━┓
┃   ┃ 0 ┃ 1 ┃ 2 ┃  3 ┃
┡━━━╇━━━╇━━━╇━━━╇━━━━┩
│ 0 │ 0 │ 1 │ 1 │  1 │
│ 1 │ 1 │ 2 │ 3 │  4 │
│ 2 │ 1 │ 3 │ 6 │ 10 │
└───┴───┴───┴───┴────┘
```

## `tabulate(rows, headers=(), row_labels=())`

A table with your own labels. Each distinct number gets its own colour.

```python
tabulate([[0, 1, 2], [1, 1, 2]], headers=list("abc"), row_labels=["x", "y"])
```

```text
┏━━━┳━━━┳━━━┳━━━┓
┃   ┃ a ┃ b ┃ c ┃
┡━━━╇━━━╇━━━╇━━━┩
│ x │ 0 │ 1 │ 2 │
│ y │ 1 │ 1 │ 2 │
└───┴───┴───┴───┘
```

## `draw_tree(root)`

A binary tree. `print(root)` does the same for a `TreeNode`.

```python
root = build_tree([4, 2, 7, 1, 3, 6, 9])
draw_tree(root)
```

```text
      [4]
   ┌───┴───┐
  [2]     [7]
 ┌─┴─┐   ┌─┴─┐
[1] [3] [6] [9]
```

## `draw_linked_list(head)`

A linked list. `print(head)` does the same for a `ListNode`.

```python
head = ListNode(1, ListNode(2, ListNode(3)))
draw_linked_list(head)
```

```text
 1 → 2 → 3
```

## `draw_ascii_graph(adj)`

A graph from a dict of lists or a dict of dicts. `print(adj)` does the same.

```python
adj = {0: [1, 2], 1: [3], 2: [3], 3: []}
draw_ascii_graph(adj)
```

```text
       [0]
        ↓
    [1]←+─→[2]
     ↓      ↓
     +→[3]←─+
```

## `draw_graph(adj)`

The same graph as an adjacency matrix.

```python
adj = {0: [1, 2], 1: [3], 2: [3], 3: []}
draw_graph(adj)
```

## `draw_heap(heap)`

A heap stored as a list, drawn as the tree it represents.

```python
heap = [1, 3, 2, 7, 4]
draw_heap(heap)
```

```text
     [1]
   ┌──┴──┐
  [3]   [2]
 ┌─┴─┐
[7] [4]
```

## `@viz_binary_search`

Traces a binary search: one bar per step, with mid marked by ok(mid).

```python
@viz_binary_search(width=60)
def firstTrue(lo, hi, ok):
    while lo < hi:
        mid = (lo + hi) // 2
        if ok(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo

firstTrue(0, 20, lambda x: x * x >= 50)
```
