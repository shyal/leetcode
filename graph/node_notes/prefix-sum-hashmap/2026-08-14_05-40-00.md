```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        D = defaultdict(int)
        D[0] = 1
        prefix = 0
        res = 0
        for n in nums:
            prefix += n
            res += D[prefix - k]
            D[prefix] += 1
        return res
```

An interesting variation:

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        D = defaultdict(int)
        D[k] = 1
        prefix = 0
        res = 0
        for n in nums:
            prefix += n
            res += D[prefix]
            D[prefix + k] += 1
        return res
```

Another variation worth exploring, of the same problem (not technique):

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        prefix = [*enumerate([0, *accumulate(nums)])]
        pos = defaultdict(list)
        [pos[p].append(i) for i, p in prefix]
        for i, p in prefix:
            print(f'bisect_left({pos[p - k]}, {i})')
        return sum(bisect_left(pos[p - k], i) for i, p in prefix)
```

It's a little tricky to visualize, because the D row gets incremented last. Next we'll add a kink by introducing a zero in nums.

![a zero makes a prefix repeat: nums = [1,2,0], k = 3](2026-08-14_prefix_sum_hashmap_zero.svg)

As we can see above, the zero adds a second subarray sum equals k, starting at the same position (0). Since `prefix - k = 1`, we increment res a second time because of D's `0:1`. Also notice that since the prefix doesn't increment when `nums[i] == 0`, D now gets `3:2`.
