The Technique Palace

Thirteen rooms off one corridor, one station per atomic move — built from graph/nodes.json, lit by graph/evidence.json. Walk it in order; the route never changes.

How to use it: when a problem appears, find the room first (what kind of question is this?), then the station (which move answers it). Each station has a fixed image to hang the move on, and its trigger — the cue that should fire it. Problem numbers carry their Major-system consonant skeleton (217N·T·K) so you can peg the canonical exemplars; 6 = J/SH/CH, 7 = K/G, 9 = P/B, as usual.
