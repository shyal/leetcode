DRILL: Nines
TRAINS: design-availability-numbers

State the downtime per year that 99.9% availability allows, and the downtime
per year that 99.99% allows. Two components are each 99.9% available. Give
the formula and the result for their total availability in sequence, then in
parallel.

REQUIRED: both yearly downtimes to within a few minutes, both formulas, both
results. Adding the availabilities is the fail.

## Answer

Got the availabilities right and sequence right, parallel wrong.

99.9% avail:

```
minutes_99_9 = (365 * 24 * 60) * (1 - 0.999)
print(minutes_99_9)
```

99.99% avail:

```
minutes_99_99 = (365 * 24 * 60) * (1 - 0.9999)
print(minutes_99_99)
```

sequence:

```
sequence = 0.999 * 0.999 = 0.998001
```

parallel:

```
parallel = 1 - (1 - 0.999) * (1 - 0.999)
```
