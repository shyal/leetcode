## Q1. 4070. Minimum Rotations to Dial a Number I

Accepted on the first submission, at 00:13:20. The dial starts at 0, so a
0 is put in front of the string. Each step from digit `a` to digit `b`
costs the shorter way round the dial: `min(abs(b - a), abs(a - b + 10),
abs(b + 10 - a))`. The sum of the steps is the answer. 999 of 999 test
cases, 2 ms.

```mu
class Solution
  def minRotations(s: str) -> int
    s = '0' + s
    ret res = 0
    for a, b in zip(s, s[1:])
      a, b = int(a), int(b)
      r = min(abs(b - a), abs(a - b + 10), abs(b + 10 - a))
      res += r
```

## Q3. 4072. Maximum Alternating Subarray Sum With One Deletion

Not solved. Two submissions, neither accepted.

Both submissions take the whole array, with at most one element deleted,
as the chosen subarray. Four prefix and suffix sums give the even-index
sum and the odd-index sum on each side of a deleted index, so each
deletion is tested in constant time. The first submission, at 00:54:46,
returned 0 on `[-72]`, where -72 is expected: a deletion that empties the
array was counted. 344 of 999 test cases.

```mu
class Solution
  def maxAlternatingSum(nums: [int]) -> int
    e_sum_front = [*scan(+, (x if i is even else 0) for >i, x in nums)]
    e_sum_back = [*scan(+, [(x if i is even else 0) for >i, x in nums], reverse=true)]
    o_sum_front = [*scan(+, (x if i is odd else 0) for >i, x in nums)]
    o_sum_back = [*scan(+, [(x if i is odd else 0) for >i, x in nums], reverse=true)]

    ret res = e_sum_front[-1] - o_sum_front[-1]
    for >i in nums
      r = (e_sum_front[i] + o_sum_back[i]) - (o_sum_front[i] + e_sum_back[i])
      res = max(res, r)
```
