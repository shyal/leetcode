## Q1. 4092. Binary Digit Score

```mu
class Solution
    def calculateScore(a: int, b: int) -> int
        def setBits(x)
            count = 0
            while x
                count += x & 1
                x >>= 1
            count
        s1 = setBits(a)
        s2 = setBits(b)
        if s1 >= s2
            return s1 * s2
        return (s2 // s1) if s1 != 0 else 0
```

## Q2. 4093. Maximize Sum After At Most K Digit Rearrangements

Note: I built the sorting array quickly, but I sorted it on the rearranged
value, not on the rearranged value minus the original. The answer was wrong
and I could not see why. I pasted an array in mu and stepped through it by
hand, left the problem, and came back to it. On the return I saw that the
rearranged value alone gives the wrong order, and sorted on the difference.

```mu
class Solution
    def maximizeSum(nums: [int], k: int) -> int
        flip = x -> to_int(sort(to_digits(x), reverse=true))
        arr = [[flip(x) - x, flip(x), x, i] for >i, x in nums]
        arr.sort(reverse=true)
        ops = 0
        total = 0
        for diff, flipped, orig, i in arr
            if flipped != orig and ops < k
                ops += 1
                total += flipped
            else
                total += orig
        total
```

## Q3. 4094. Count Frequency Staircase Subarrays I

Note: I did not read the statement properly on the first pass and spent the
time on groupby. I left the problem, came back to it, and saw "in the order
of their first appearance". That one clause gave the helper its logic.

The first version sliced every subarray and counted it from scratch. It hit the
time limit:

```python
class Solution:
    def countStaircase(self, nums: list[int]) -> int:
        def is_frequency_staircase(arr):
            counts = Counter(arr)
            appearances = [x[0] for x in groupby(arr)][:len(counts)]
            for i, v in enumerate(appearances):
                if counts[v] != i + 1:
                    return False
            return True
        total = 0
        for i in range(0, len(nums)):
            for j in range(i, len(nums)):
                ss = nums[i:j + 1]
                isfs = is_frequency_staircase(ss)
                total += isfs
        return total
```

The accepted version extends the right end one element at a time and updates
the counts and the first-appearance order as it goes:

```python
class Solution:
    def countStaircase(self, nums: list[int]) -> int:
        def is_frequency_staircase(i, j, counts, in_order):
            for i, v in enumerate(in_order):
                if counts[v] != i + 1:
                    return False
            return True
        total = 0
        for i in range(0, len(nums)):
            counts = Counter()
            app = set([])
            in_order = []
            for j in range(i, len(nums)):
                if nums[j] not in app:
                    app.add(nums[j])
                    in_order.append(nums[j])
                counts[nums[j]] += 1
                isfs = is_frequency_staircase(i, j+1, counts, in_order)
                total += isfs
        return total
```
