## Q1. 1629. Slowest Key

I was still waking up, and wrongly incremented `times[keysPressed[i-1]]` instead of
taking its max. I blanked so asked Claude for a tip.

```python
class Solution:
    def slowestKey(self, releaseTimes: list[int], keysPressed: str) -> str:
        times = defaultdict(int)
        releaseTimes = [0] + releaseTimes
        for i in range(1, len(releaseTimes)):
            d = releaseTimes[i] - releaseTimes[i-1]
            times[keysPressed[i-1]] = max(times[keysPressed[i-1]], d)
        return max(times.items(), key=lambda x: (x[1], x[0]))[0]
```

## Q2. 1630. Arithmetic Subarrays

```python
class Solution:
    def checkArithmeticSubarrays(self, nums: list[int], l: list[int], r: list[int]) -> list[bool]:
        res = []
        def isArith(s):
            s.sort()
            return len(set([a - b for a, b in zip(s, s[1:])])) == 1
        for L, R in zip(l, r):
            res.append(isArith(nums[L:R+1]))
        return res
```

## Q3. 1631. Path With Minimum Effort

I hit a TLE because i forgot about continuing right after a pop
if the item is in seen:

```python
    if (r, c) in seen:
        continue
```

So i got hinted by Claude. Given that my first attempt at Disjkstra was yesterday,
i'm not too displeased.

```python
class Solution:
    def minimumEffortPath(self, heights: list[list[int]]) -> int:
        q = [(0, 0, 0)]
        seen = set([])
        res = 0
        while q:
            weight, r, c = heappop(q)
            if (r, c) in seen:
                continue
            seen.add((r, c))
            if r == len(heights) - 1 and c == len(heights[0]) -1:
                return weight
            for rr, cc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                rr, cc = r + rr, c + cc
                if 0 <= rr and rr < len(heights) and 0 <= cc and cc < len(heights[0]):
                    if (rr, cc) not in seen:
                        diff = abs(heights[r][c] - heights[rr][cc])
                        heappush(q, (max(diff, weight), rr, cc))
```
