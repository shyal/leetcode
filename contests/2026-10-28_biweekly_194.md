## Q1. 4088. Difference Between Peaks and Valleys

Note: Q1 was easy and I solved it very fast.

```mu
class Solution
  def peakValleyDifference(nums: [int]) -> int
    peaks = 0
    valleys = 0
    for i in 1..<len(nums)-1
      peaks += nums[i-1] < nums[i] > nums[i+1] ? nums[i] : 0
      valleys += nums[i-1] > nums[i] < nums[i+1] ? nums[i] : 0
    peaks - valleys
```

The accepted submission, at 01:06:13, walks the array once. It counts the
length of each block of elements in range, and adds the number of subarrays
inside that block when the block ends. The sentinel `inf` at the end closes
the last block. Linear time.

```mu
class Solution
  def countSubarrays(nums: [int], minK: int, maxK: int) -> int
    ret res = 0
    good = 0
    start = 0
    nums += [inf]
    for >i, v in nums
      if minK <= v <= maxK
        if good == 0
          start = i
        good += 1
      else
        if good
          n = i - start + 1
          res += n * (n - 1) // 2
        good = 0
```

```mu
class Solution
  def countMagicalPairs(s: str) -> int
    def count_uniques(a)
      a_counts = counter(a)
      a_unique = []
      for ac in a
        a_unique <- len(a_counts.keys())
        a_counts[ac] -= 1
        if a_counts[ac] == 0
          del a_counts[ac]
      counter(a_unique)

    ret res = 0
    n = len(s)
    D = {:int}
    for j in 1..<len(s)
      a = s[:j]
      b = s[j:]
      au = count_uniques(a)
      bu = count_uniques(b)
      matching_keys = set(au) & set(bu)
      for key in matching_keys
        res += max(au[key], bu[key])
```
