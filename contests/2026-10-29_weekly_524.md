## Q1. 4083. Minimum Deletions to Make Array Sharp

Accepted on the first submission, at 00:10:47. Each equal adjacent pair costs
one deletion.

```mu
class Solution
  def minDeletions(nums: [int]) -> int
    ret res = 0
    for a, b in zip(nums, nums[1:])
      res += a == b
```

## Q2. 4084. Last Visited Cell in a Directional Grid

Accepted on the first submission, at 00:22:51. A walk from (0, 0) that follows
the arrow in each cell and stops at the cell before the first step out of the
grid or onto a cell already visited.

```mu
class Solution
  def lastVisitedCell(grid: [[str]]) -> [int]
    dirs = {
      'U': (-1, 0),
      'D': (1, 0),
      'R': (0, 1),
      'L': (0, -1),
    }
    pos = (0, 0)
    seen = set([pos])
    while true
      dir = grid[pos[0]][pos[1]]
      new_dir = dirs[dir]
      prev_pos = pos[:]
      pos = (pos[0] + new_dir[0], pos[1] + new_dir[1])
      is_out = not in_bounds(grid, pos[0], pos[1])
      if is_out
        return prev_pos
      if pos in seen
        return prev_pos
      seen.add(pos)
```
