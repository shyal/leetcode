## Q1. 4065. Rearrange Array by Removing Distinct Values

Accepted on the first submission, at 00:02:52. A counter holds the
occurrences of each value. While the counter has keys, each key goes to the
answer in sorted order and its count goes down by 1; a key at 0 is
deleted. 1000 of 1000 test cases, 10 ms.

```mu
class Solution
  def rearrangeArray(nums: [int]) -> [int]
    ret ans = []
    counts = Counter(nums)
    while counts
      for k in [*sorted(counts)]
        ans.append(k)
        counts[k] -= 1
        if counts[k] == 0
          del counts[k]
```
